# Schott Platform v0.2.0

**Release:** Foundation

## Overview

Version 0.2.0 establishes the governance and architectural foundation for the Schott Platform. This release focuses on standards, documentation, security policy, and engineering discipline rather than infrastructure deployment.

The goal is to ensure future implementation and automation are guided by documented architecture and validated standards.

## Highlights

### Architecture

- Established the Network Architecture document.
- Defined the management, application, and private service boundaries.
- Documented the current flat network with a migration path toward VLAN-based segmentation.

### Platform Standards

Introduced formal engineering standards:

- Linux Server Security Standard
- Service Exposure Standard
- Network Policy
- Platform Roadmap

### Architecture Decisions

Added the first Architecture Decision Record:

- ADR-0001 — `schai` as the Reference Host

This defines the engineering workflow:

1. Design
2. Manual implementation on `schai`
3. Validation
4. Documentation
5. Automation with Ansible
6. Broad deployment

### Governance as Code

Added static documentation validation to verify:

- Required governance documents exist.
- Architecture Decision Records follow a consistent structure.
- Standards continue documenting required topics.
- Network policy remains aligned with architecture.
- Markdown links remain valid.

## Engineering Principles

This release formally adopts:

- Manual once. Automated forever.
- Infrastructure as Code.
- Security by default.
- Design before implementation.
- Validate before rollout.
- Document significant architectural decisions.
